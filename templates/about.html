🎯 Project Goal

Build a full-stack AI web application that detects human faces from images and predicts age group and gender using OpenCV DNN models, while storing user data and results securely using Supabase and Cloudinary.

🚀 Deployment

The system is fully deployable on cloud platforms like Render, with Supabase handling the database and Cloudinary managing image storage.
